# TrainCheck 0.2.0

This beta release adds parallel offline inference/checking, accelerates trace
queries, and fixes instrumentation and inference correctness issues. It includes
the reviewed changes from PRs #139–#148, consolidated on main by #151.

## Highlights

- Process-based offline inference and checking via `--num-workers`, with
  deterministic inference sampling across tested worker counts and schedules.
- Bounded example reservoirs during construction and merging, with validated
  worker configuration and accurate represented-population counts.
- Context/call indexes, cached process/thread identities, and indexed time-window
  queries for offline invariant inference.
- Exception-safe recorder suppression and atomic buffer delivery to prevent
  recorder recursion and duplicate or lost batches.
- Preserved TorchScript builtin mappings and robust dynamic type-name handling.
- Independent pruning state for each precondition solve.
- Typed fresh-run validation utilities with explicit activation, coverage,
  unsupported, skipped, and failed states.
- Correct standard console-entrypoint metadata for all four commands.

## Measured performance

These are complete offline-inference timings on a saved trace from a 10-step,
6,163,712-parameter TorchTitan Llama debug training run: 573,494 events, batch size
1, sequence length 256. Inference ran on labmach's CPU with one worker/native
thread and six enabled relations.

| Experiment | Before | After | Scope |
| --- | ---: | ---: | --- |
| Process/thread identity caching | 1,385.656 s | 98.551 s | One baseline-first paired run; 14.06x |
| Time-window indexing | 101.796 s | 76.748 s | Medians across three alternating paired runs; 24.61% less wall time |

Outputs match within each comparison. The experiments use different corrected
baselines; do not multiply their speedups or claim that either measures training,
trace-collection overhead, distributed scaling, or model quality.
See [identity-cache evidence](../measurements/inference-identity-cache.md) and
[time-window evidence](../measurements/inference-time-range-index.md) for exact
source/input hashes, memory costs, commands, and limitations.

## Compatibility and limits

Python 3.10 or newer remains required. Standard pip-installed command names are
unchanged. Packaging checks cover both wheel and source distributions.

Reservoir-cap and pruning-state corrections can change inferred evidence or
predicates. This release is not solely an output-preserving performance update.
Trace indexes assume stable dataframe values, dtypes, and row order; create a new
`TracePandas` after unsupported in-place mutation.

Fresh-run validation reports use schema version 2, retaining unknown totals as
`null` with explicit observation/error states. The Transformer study still
contains two healthy false alarms associated with embedded object identities.
TorchScript compatibility uses private PyTorch APIs and reports missing support;
it does not establish general Megatron/checkpoint compatibility.

Benchmark and fresh-validation utilities are available in the repository/source
distribution, not installed as part of the wheel. Legacy untyped bodies are not
all strictly checked. Three unchanged repository-wide formatting issues remain
outside the release-preparation changes.

The consolidated production/harness stack passed 168 regression tests. Release

interpreters, negative metadata/location contracts, required static-analysis
